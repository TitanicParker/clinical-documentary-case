# \# Clinical Documentary Case — Propositions

# 

# \*\*Status:\*\* Controlled proposition layer derived from `FACTS.md` and `TENSIONS.md`.

# 

# > \*\*Control rule:\*\* A proposition synthesises documentary facts and tensions. It is not itself a finding of negligence, breach, causation, motive, dishonesty or legal liability. Questions requiring specialist clinical judgment remain for independent expert opinion.

#

# \## PROP-0001 — The presentation entered Neurology as an integrated unresolved clinical problem

# 

# \*\*Proposition:\*\*  

# Before hospital assessment, feet, gait, movement initiation, lower-limb tone, toe clawing, dexterity and functional impairment were sufficiently interconnected in the contemporaneous GP record to form one evolving neurological referral presentation.

# 

# \*\*Principal facts:\*\* FACT-0001, FACT-0002, FACT-0042, FACT-0043, FACT-0044, FACT-0045, FACT-0046  

# \*\*Tensions:\*\* TENSION-0001

# 

# \*\*Boundary:\*\*  

# This does not establish one common mechanism for every symptom.

#

# 

# \## PROP-0002 — Structural foot pathology and neurological lower-limb abnormality genuinely coexisted

# 

# \*\*Proposition:\*\*  

# The documentary record independently establishes recurrent structural/mechanical foot pathology and a neurological lower-limb phenotype involving abnormal tone, dystonic-looking gait, clawing and later Parkinsonian/dyskinetic phenomena.

# \## PROP-0003 — The 2017 foot–neurology relationship was expressly unresolved

# 

# \*\*Proposition:\*\*  

# The July 2017 neurological record did not establish that the foot and neurological problems were unrelated. It expressly preserved competing possibilities and concluded that the relationship was “Not clear.”

# 

# \*\*Principal facts:\*\* FACT-0047, FACT-0048, FACT-0050, FACT-0051  

# \*\*Tensions:\*\* TENSION-0001, TENSION-0002

# 

# \*\*Boundary:\*\*  

# The patient's own contemporaneous distinction between foot pain and leg tension remains part of the evidence.

#

# \## PROP-0004 — Operational separation did not itself resolve the clinical relationship

# 

# \*\*Proposition:\*\*  

# Routing the structural foot problem to Podiatry while Neurology managed Parkinsonism created a practical division of care, but the documentary record does not show that this operational allocation converted the earlier uncertainty into a settled etiological conclusion.

# \*\*Principal facts:\*\* FACT-0050, FACT-0052, FACT-0084–FACT-0091  

# \*\*Tensions:\*\* TENSION-0001, TENSION-0002, TENSION-0003

# 

# \*\*Boundary:\*\*  

# Parallel Neurology and Podiatry management may have been clinically appropriate.

# \## PROP-0007 — Dopaminergic treatment was deliberately deferred as a longitudinal strategy

# 

# \*\*Proposition:\*\*

# \## PROP-0008 — The record simultaneously anticipated substantial benefit from dopaminergic treatment

# 

# \*\*Proposition:\*\*  

# The deferral strategy coexisted with repeated acknowledgment that conventional dopaminergic treatment could provide substantial improvement, would probably eventually be required, and might later be regretted if not commenced earlier.

# 

# \*\*Principal facts:\*\* FACT-0009, FACT-0011, FACT-0012, FACT-0034, FACT-0054, FACT-0059, FACT-0098, FACT-0099  

# \*\*Tensions:\*\* TENSION-0005

# 

# \*\*Boundary:\*\*

# 

# \*\*Proposition:\*\*

# \*\*Principal facts:\*\* FACT-0039, FACT-0053, FACT-0054, FACT-0098  

# \*\*Tensions:\*\* TENSION-0006

# 

# \*\*Boundary:\*\*

# \## PROP-0014 — Dopaminergic pain relief establishes interaction with treatment state, not a unique pain mechanism

# 

# \*\*Proposition:\*\*  

# Repeated improvement in pain when Sinemet was effective establishes clinically important interaction between dopaminergic state and pain experience. The same record expressly warns that such relief can occur even when the underlying pain has another cause.

# 

# \*\*Principal facts:\*\* FACT-0024, FACT-0028, FACT-0038, FACT-0079, FACT-0094, FACT-0095  

# \*\*Tensions:\*\* TENSION-0012

# 

# \*\*Boundary:\*\*  

# Medication-related pain relief does not distinguish, by itself, among dystonic, neuropathic, mechanical, structural or mixed pain generators.

# \## PROP-0015 — The 2025 Sinemet CR outcome strengthens the treatment-timing question

# 

# \*\*Proposition:\*\*  

# The 2025 record moves beyond predicted benefit: cautious introduction/escalation of Sinemet CR was followed by a clinician-recorded state of “profound relief currently,” while Quality and Patient Safety subsequently described Sinemet CR as an effective analgesic for the foot pain.

# 

# \*\*Principal facts:\*\* FACT-0082, FACT-0083, FACT-0101, FACT-0102, FACT-0103  

# \*\*Tensions:\*\* TENSION-0014

# 

# \*\*Boundary:\*\*  

# The successful 2025 outcome does not prove that the same intervention would have produced the same benefit-to-harm balance at an earlier date.

# \## PROP-0019 — The central issue is the timing of reassessment

# 

# \*\*Proposition:\*\*  

# The strongest documentary question is not whether the original 2017 mixed-management strategy was necessarily wrong. It is whether, and at what point, accumulating pharmacological, neurological, OFF-state, treatment-response and genetic evidence made continued reliance on the original symptom partition or treatment strategy clinically inadequate without explicit reassessment.

# 

# \*\*Principal facts:\*\* FACT-0050, FACT-0033, FACT-0034, FACT-0035, FACT-0024, FACT-0036, FACT-0072, FACT-0101, FACT-0092  

# \*\*Tensions:\*\* TENSION-0016

# 

# \*\*Boundary:\*\*  

# Identification of any reassessment threshold and its clinical consequences requires independent expert judgment.

# 

# \---

# 

# \## PROP-0020 — The strongest clinical case is longitudinal rather than retrospective absolutism

# 

# \*\*Proposition:\*\*  

# The documentary case does not require a finding that all foot symptoms were neurological, that Podiatry was inappropriate, or that levodopa should necessarily have been started in July 2017. Its stronger form is that an initially mixed and expressly unresolved presentation accumulated evidence over time that required continuing clinical integration and reconsideration.

# 

# \*\*Principal tensions:\*\* TENSION-0001 through TENSION-0016

# 

# \*\*Boundary:\*\*  

# Whether reasonable clinical practice required a change at any particular decision point remains an expert question.

# 

# \---

# 

# \# Governing proposition

# 

# > \*\*The clinical record begins with genuine structural foot pathology and severe neurological disease whose relationship was expressly “Not clear.” Parallel management may initially have been reasonable. The material question is whether subsequent treatment-state evidence, dystonic and Parkinsonian lower-limb findings, explicit OFF-related undertreatment, major Sinemet CR benefit and eventual genetically confirmed Parkin-associated Parkinsonism and dystonia created one or more points at which the original explanatory partition and dopaminergic treatment strategy required explicit reassessment.\*\*
